**Goal:** Test ₹500–₹1,000/day for 7 days, then scale winners.

**Landing page:** https://www.visriva.com/reserve  
**UTM format:** `?utm_source=meta&utm_medium=paid&utm_campaign=wedding_aug26`

---

## Before you start

- [ ] Instagram account is **Business** or **Creator** (not personal)
- [ ] Instagram linked to Facebook Page ("Visriva Live Station")
- [ ] Meta Business Suite access: [business.facebook.com](https://business.facebook.com)
- [ ] Payment method added (card/UPI via Meta billing)
- [ ] `/reserve` page loads fast on mobile (test on your phone)
- [ ] WhatsApp widget works on site

## Campaign 1 — Wedding leads (Traffic)

### Step 1: Create campaign
- **Objective:** Traffic (or Leads if you add Instant Form later)
- **Campaign name:** `VISRIVA_Wedding_Traffic_Aug26`
- **Advantage Campaign Budget:** ON
- **Daily budget:** ₹500 (test) → ₹1,500 (scale)

### Step 2: Ad set
| Setting | Value |
|---------|-------|
| Conversion location | Website |
| Website URL | `https://www.visriva.com/reserve?utm_source=meta&utm_medium=paid&utm_campaign=wedding_traffic` |
| Performance goal | Link clicks or Landing page views |
| Audience location | Bengaluru + 25 km **OR** Karnataka if budget allows |
| Age | 24–40 |
| Interests | Wedding planning, Engagement, Bridal, Luxury wedding, Event planning |
| Placements | Advantage+ placements (let Meta optimize) |
| Start date | Today |
| End date | None (pause manually after review) |

### Step 3: Ad creative
**Format:** Single video (15–30 sec Reel) or carousel (3 event photos)

**Primary text (Variant A):**
```
Your guests deserve more than a basic photo booth.

Visriva sets up luxury live gifting stations at your wedding — instant photo strips, live magnets, keychains & more. Designed for your event. Crew included.

Bengaluru + pan-India. Peak season dates filling fast.

Tap below to check availability & get a custom quote in minutes.
```

**Primary text (Variant B — urgency):**
```
Still finalising your wedding vendors?

Add a live station guests actually queue for — printed keepsakes in seconds, custom branded for your sangeet or reception.

Visriva · Luxury live experiential gifting
Reserve your date →
```

**Headline:** `Luxury Wedding Live Stations`  
**Description:** `Bengaluru · Photo Booth · Magnets · Custom Branding`  
**CTA button:** `Book Now` or `Learn More`

**Media:** Best wedding BTS Reel you have. Add logo watermark.

### Step 4: Launch
- [ ] Preview on mobile + desktop
- [ ] Publish
- [ ] Check ad status = Active (can take 1–24h for review)

## 7-day test plan

| Day | Action |
|-----|--------|
| 1 | Launch Wedding campaign ₹500/day |
| 2 | Check CTR > 1%; if below 0.5%, swap creative |
| 3 | Launch Corporate ₹300/day (split test) |
| 4 | Pause worst ad set |
| 5 | Duplicate winner with new headline |
| 6 | Review `/reserve` submissions — ask "how did you hear about us?" |
| 7 | Decide: scale to ₹1,500/day or fix landing page |

---

## KPIs to watch

| Metric | Good benchmark |
|--------|----------------|
| CTR (link) | > 1% |
| CPC | < ₹15 (India, luxury niche) |
| Cost per reserve submit | < ₹500 (ideal; varies) |
| Landing page bounce | < 60% |

Check in Ads Manager → Campaigns → Columns → Customize → add Link clicks, CPC, Landing page views.

## Track bookings from ads

In your booking form notes field, users sometimes say "Instagram ad."

Better: check Firestore bookings for UTM if you add hidden field later.

**Manual for now:** Google Sheet column `source` = meta_wedding / meta_corporate / organic_ig

---

## Common mistakes

| Mistake | Fix |
|---------|-----|
| Sending traffic to homepage | Always `/reserve` |
| No mobile test | 90% traffic is phone |
| One ad, no variants | Run 2 primary texts minimum |
| Stopping after 2 days | Allow 5–7 days for learning |
| Broad India targeting | Start Bengaluru wedding niche |
| No clear CTA in video | Text overlay: "Book at visriva.com/reserve" |

---

## Scale checklist (when winning)

- [ ] Increase budget 20% every 3 days on winning ad set
- [ ] Add lookalike audience (1% Bengaluru) from website visitors
- [ ] Refresh creative every 14 days (ad fatigue)
- [ ] Add testimonial/Reviews to `/reserve` page
- [ ] Install Meta Pixel + track `Lead` event on form submit
