## Quick start (first 3 days)

1. Update Instagram bio (see calendar Day 1).
2. Connect **ManyChat** → Instagram → import flows from `dm-automation-flows.md`.
3. Schedule Week 1 Reels in **Meta Business Suite** or **Later**.
4. Open `lead-tracker.csv` in Google Sheets; DM 10 planners today.
5. Launch first Meta ad using `meta-ads-checklist.md` (₹500/day test).
